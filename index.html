памятка руководителю

  • 1

    Своевременно обеспечивать организацию рабочего места для нового сотрудника*

    • Назначает наставника для нового сотрудника (в небольших структурных подразделениям руководитель может выполнять функцию наставника)
    • Утверждает план адаптации для нового сотрудника в АСУ HR
    • Проставляет отметки о выполнении мероприятий
    *не позднее, чем за 1 день до выхода на работу
  • 2

    Своевременно обеспечивать организацию рабочего места для нового сотрудника*

    • Обеспечивает необходимой информацией: о бизнес-процессах подразделения, схеме взаимодействия с заинтересованными сторонами (другие структурные подразделения/ внешние организации)
    • Проясняет цели подразделения и задачи нового сотрудника
    • Своевременно дает новому сотруднику обратную связь
  • 3

    Своевременно обеспечивать организацию рабочего места для нового сотрудника*

    • Работа с планом адаптации
    • Инструкции по работе в Модуле Адаптации
    *необходимого для эффективного выполнения рабочих задач
